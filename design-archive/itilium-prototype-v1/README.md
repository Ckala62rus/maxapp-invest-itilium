# ITILIUM Prototype Archive v1

Этот каталог хранит понравившийся собранный snapshot дизайна MAX ITILIUM.

## Что внутри
- `index.html`
- `assets/index-CnC4y5vW.css`
- `assets/index-D7ePxk2g.js`

## Зачем это нужно
- сохранить текущий понравившийся дизайн отдельно от дальнейшей переработки `frontend/`
- иметь готовый статический вариант для переиспользования в будущем

## Как открыть
- можно открыть `index.html` напрямую в браузере
- или отдать каталог любым статическим сервером

## Важно
- это архив собранной версии интерфейса, а не исходники для разработки
- текущая рабочая разработка продолжается в `frontend/`
